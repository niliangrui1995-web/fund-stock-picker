# 出海钱眼

本项目把 `outputs/holdings_stock_2026q1.csv` 里的基金股票持仓明细，整理成一个面向大陆客户海外股票投资需求的本地网站：用户输入美股、港股或海外股票代码后，页面返回持仓该股最高的前 10 只非指数、非 ETF 基金；首屏热门候选采用美股优先、港股兼容的口径。

## 当前方案

- 默认排名口径：按“该股票占基金净值比例”排序，用来识别基金对单只股票的集中度。
- 辅助排名口径：按“持仓市值(万元)”排序，用来识别大资金规模基金。
- 展示字段：基金代码、基金名称、基金类型、净值占比、持仓市值、持股数、申购状态、赎回状态和申购限制。
- 数据周期：当前使用 `2026Q1`，截止日来自原始持仓明细。
- 发布数据：前端 JSON 只下发海外股票检索范围，源数据总量仍在元数据中保留，避免公开访问时加载完整 A 股持仓索引。

## 本地运行

```powershell
python scripts\build_fund_stock_index.py
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/`。

## 发布前检查

```powershell
python scripts\build_fund_stock_index.py
npm run build
npm audit --audit-level=moderate
npm run preview
```

生产预览默认打开 `http://127.0.0.1:4173/`。发布前至少验证：

- 页面首屏不空白，标题为“出海钱眼”，控制台无错误。
- `NVDA`、`00700`、`TSM` 等海外标的可以命中基金榜单。
- “净值占比 / 持仓市值”切换可用，热门市场筛选可用。
- 桌面与移动端布局无明显遮挡、溢出或不可读文本。

## 发布口径

- `public/data/fund-stock-index-2026q1.json` 是前端实际加载的数据文件。
- 当前发布数据只包含海外股票检索范围：`742` 个海外标的；源数据全量股票数保留在 `meta.totalStockCount`。
- 当前生成数据约 `4.28 MB`，gzip 后约 `0.50 MB`。
- `public/_headers` 配置了基础安全响应头，并为指纹静态资源与数据 JSON 设置缓存策略。
