# 基金持仓穿透网站

本项目把 `outputs/holdings_stock_2026q1.csv` 里的基金股票持仓明细，整理成一个本地可运行的网站：用户输入股票名称或证券代码后，页面返回持仓该股最高的前 5 只基金。

## 当前方案

- 默认排名口径：按“该股票占基金净值比例”排序，用来识别基金对单只股票的集中度。
- 辅助排名口径：按“持仓市值(万元)”排序，用来识别大资金规模基金。
- 展示字段：基金代码、基金名称、基金类型、净值占比、持仓市值、持股数、天天基金来源链接。
- 数据周期：当前使用 `2026Q1`，截止日来自原始持仓明细。

## 本地运行

```powershell
python scripts\build_fund_stock_index.py
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/`。
