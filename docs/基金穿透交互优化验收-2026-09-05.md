# 基金穿透交互优化验收

本轮针对用户反馈的“搜索和查看结果不顺”“公司代码和名称还没有完全统一和合并”。跨市场证券分别保留；同市场同证券的已核实代码别写才归一。

## 与原 UI / UX 审查的对应

| 原审查项 | 本轮调整 | 验收重点 |
|---|---|---|
| 1 · 证券身份与市场 | 扩展证券标识核验，统一搜索、结果和详情展示；请求携带稳定身份修订号，更新旧缓存 | 同市场别名归一；同公司跨市场、ADR 与正股、不同股份类别保持独立；原披露可回查 |
| 2 · 口径一致 | 对已核实港股直持与港股通分行披露汇总；跨市场撞码按报告行拆分；解析残片排除搜索及聚合 | 不丢真实持仓；不把同基金不同份额再次相加；原披露与解析待核对记录可回查 |
| 4 · 组合保存 | 首次保存才弹出命名框；我的组合直接显示可点列表；更多操作保留另存为、重命名、新建和删除 | 保存失败、取消与未保存保护；列表切换后焦点可继续操作 |
| 6、7 · 搜索到结果 | 默认只显示一个搜索框；单股结果直接接在搜索后。组合选股按需展开，选中即加入，查看结果后收起 | 鼠标查询保留输入焦点、选中代码可直接替换；键盘查询定位本次结果；多市场名称或别名需明确选择，标准代码可直接回车；取消切换不重开建议、不丢草稿 |
| 8、9 · 结果与详情 | 保留桌面表格、手机卡片、分类分页、构成和详情检索 | 新流程不影响持仓回查和基金比较；不同市场在候选、标题和详情中可辨认 |
| 3、5、10、11 · 布局、图表、恢复 | 保留前轮精简布局与数据逻辑 | 对两融、交易集中度、方法论进行窄屏与导航回归；坏包/断网保护继续有效 |

## 市场区分与数据边界

- 同公司不同上市市场、ADR 与正股、不同股份类别分别计算。香港直持与港股通是同一港股的交易路径，只有证券标识核实一致时合并。
- 对 ROP、2883、6088、ASX、BBY、BG、DTE、PRU、RIO、SAN、ASML 共 11 组真实混合代码，以官方报告市场和证券标识逐行区分。SAN 同一基金的西班牙 Santander 2.90% 与法国 Sanofi 1.76% 不再互相覆盖；ASML 荷兰与美国版本分别保留。
- 21 条跨页续行曾将 HK/US/UN/UW 市场后缀解析成股票代码，并把金额尾数误当占比。这些精确源行从搜索及计算中隔离；详情只显示“待核对”，展开为“原解析记录”，不把原解析数值当作有效持仓比例。
- 对这些续行关联的真实持仓，依据同一官方报告跨页原文恢复 20 处市值和 3 处股数。原始 CSV、正确持仓占比和报告来源保留，不重复累加续行。
- 输入 `ASML` 时，主搜索、组合添加和旧深链均展示美国与荷兰候选，不自动选市场；明确输入 `ASMLUS` 或 `ASML.NA` 可直接查询。`TSM` 与 `2330`、`BABA` 与 `09988`、中芯 A/H 股分别计算。
- 明细新增标准证券代码，同时保留原代码、原名称、原序号和来源。没有充分证据的代码不会仅因名称相似或后缀相同而合并。
