## 视觉与交互复核

- 核心结果正文采用14px、核心数值16px，辅助信息主要12–13px；数值等宽、右对齐。手机常用按钮、搜索、日期和选择控件按44px目标调整。
- 保存为主操作，新建/另存为为次操作，删除收进更多操作并使用危险操作样式。禁用、保存成功、未保存及失败均有文字反馈。
- 保留搜索方向键、结果页签键盘操作、对话框Escape关闭与焦点返回。结果定位避开固定导航，标题和第一条基金在窄屏同时可见。
- 发现区默认折叠，展开后先显示3个热点，按需查看更多；数据覆盖与市场环境可单独展开。

## 复核边界与交付状态

本次完成的是原报告11项实现及可在本机复现的检查。真实手机触控、真实读屏软件和用户任务访谈尚未实测；浏览器宽度/键盘/文字放大检查不能替代这些实机验证，也不构成完整WCAG认证。原报告中明确建议单独排期的覆盖数量筛选、导出及用户行为指标研究，不属于本次11项修复的验收项。

未知证券版本保持待核对是有意保留的数据边界，不代表已完成全部全球证券身份核验。当前21个白名单证券有逐项证据；其他版本没有通过删后缀或名称近似强行合并。
